Zomato Data Analysis

Coding with Python in a Jupyter notebook, working with data from a food delivery service. I manipulate the data into a Pandas dataframe and plot out various graphs using Seaborn to find different interesting conclusions.

Credit Card Fraud Detection

Using Jupyter notebook to code in Python, I work with credit card fraud data to create an AI model with SciKit-Learn to detect fraudulent claims. I create a random forest classifier and perform analysis to find solutions to performance problems. After implementing my techniques, I create more models that result in better performance than the original.
