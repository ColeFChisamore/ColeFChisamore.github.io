Zomato Data Analysis
Zomato Data Analysis

Coding with Python in a Jupyter notebook, I work with dataset about restaurant reviews and other details from a food delivery service. I manipulate the data into a Pandas dataframe and organize it in order to plot out and visualize various graphs using Seaborn. I then inspect and analyze these graphs to determine information, find interesting patterns, and draw thoughtful conclusions.

Credit Card Fraud Detection
Credit Card Fraud Detection

Using Jupyter notebook to code in Python, I work with credit card fraud data to create an AI model with SciKit-Learn to detect fraudulent claims. I create a random forest classifier model and train it, then I perform analysis on the results and the data distribution to find solutions to performance problems. After implementing my techniques, I create more models trained on less data and compare them, resulting in better performance than the original.
