Welcome to My GitHub Showcase!

This website hosts a collection of personal projects that I have completed and wanted to show off. These projects are mostly based around data collection, manipulation, and visualization, as well as some artificial intelligence and machine learning elements. Each page is dedicated to a single project and will walk through the content step by step. The purpose and function of each step is explained in detail, and there are sections of code included to show the input and output so that the entire process can be seen from beginning to end. At the bottom of each page you can follow the links to view my GitHub account or access the GitHub repository that hosts the page you are currently on.

If you would like to contact me or ask me any questions about my project, you can send me an email or chat with me on LinkedIn by using the infromation at the footer of any page.

Thank you for joining me on this journey through my projects. I hope you enjoy!

Zomato Data Analysis
Zomato Data Analysis

Coding with Python in a Jupyter notebook, I work with dataset about restaurant reviews and other details from a food delivery service. I manipulate the data into a Pandas dataframe and organize it in order to plot out and visualize various graphs using Seaborn. I then inspect and analyze these graphs to determine information, find interesting patterns, and draw thoughtful conclusions.

Credit Card Fraud Detection
Credit Card Fraud Detection

Using Jupyter notebook to code in Python, I work with credit card fraud data to create an AI model with SciKit-Learn to detect fraudulent claims. I create a random forest classifier model and train it, then I perform analysis on the results and the data distribution to find solutions to performance problems. After implementing my techniques, I create more models trained on less data and compare them, resulting in better performance than the original.

Housing Web Scraping & Analysis
Housing Web Scraping & Analysis

Starting in Python, I create a web-scraping function with BeautifulSoup that goes through real estate listing pages that are given to it. I use my function to collect thousands of pieces of information and organize them into a dataframe with Pandas.
